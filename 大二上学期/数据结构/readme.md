- 数据结构是一门极为重要的课程
  - 第一，这门课程奠定了后续诸多课程的基础，如算法设计与分析，计算机视觉；又同时与相关课程有相似的内容设置：离散数学
  - 第二，这门课程是四大考验科目中的一个
  - 第三，数据结构是很多院校的保研夏令营考试内容之一
  - 第四，这门课程几乎全部内容与CSP 100-500分有关系
- 这门课程2024级开始有三位老师授课，难度较大，理论和实践都需要较好的掌握
- 平时建议养成好的习惯
  - 每个内容都要动手写代码，要能在学完这门课之后熟练写图，树等的代码。
  - 理论部分可以结合课程所授，提前联系王道考研习题，这会对期末笔试有较大的帮助
- 这门课资料比较多，同学们可以充分利用起来！
- 给分较为友好
