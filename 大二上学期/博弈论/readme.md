- 这门课即将更名为“博弈论与多智能体”，随着人工智能的不断发展，博弈思想在研究中用的越来越多，比较常见的就是：（1）AI Agent，通过博弈设计并研究群体智能（2）其中的相关博弈有关的公式等可以用到一些研究中，例如，Sharpley 值在机器学习中用到的很多
